# Official logos

Source: Natalie brand style guide (`reference/style-guide.pdf`).  
Fill-fixed SVGs from Claude Design (`assets/logos/`) — root `fill` attributes so white/red/black render correctly (no empty Illustrator class fills / full-bleed rects).

Use these files only. Do not redraw, retype, stretch, rotate, recolor outside the three logo colorways, or add shadows/effects.

Nav/footer height: `--logo-nav-height` / `--logo-footer-height` = **80px** so the 2:1 horizontal mark clears the **160px** minimum width.

| File pattern | Use |
|--------------|-----|
| `logo-horizontal-{black\|white\|red}.svg` | Primary · wide formats (min **160px** wide) |
| `logo-stacked-{black\|white\|red}.svg` | Compact / mobile (min **120px** wide) |
| `monogram-{black\|white\|red}.svg` | Icon / stamp (min **40px**) |

**Colorways**

- Black → white / light backgrounds  
- White → black, dark photos, or brand red  
- Red → white / very light backgrounds only — never on dark or busy fields  

Script font (Sunday April) lives inside these files — never in website body/UI.
