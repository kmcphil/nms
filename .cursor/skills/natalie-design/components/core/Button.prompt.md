One-line: the site's action control — use `ink` everywhere, `red` only in the hero, `onRed` inside the single red panel.

```jsx
<Button href="/start-the-conversation">Start the Conversation</Button>
<Button variant="onRed">Start the Conversation</Button>
```

Label is always uppercase and always an action ("Start the Conversation" — never "Book a free strategy call"). One primary CTA per viewport.
