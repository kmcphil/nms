# Build process (one page at a time)

## Scaffold (done first)

1. Folder structure + routes  
2. Empty page placeholders  
3. Navigation matching the sitemap  
4. Global layout: Header → Main → Footer  

Do **not** invent homepage sections during scaffolding.

## Page build order

Build **one page**, then review, then the next:

1. Home — using the content strategy document only  
2. About  
3. Services  
4. Strategic Compass Sprint  
5. Focused Growth Retainer  
6. Strategic Repositioning Engagement  
7. Results  
8. FAQ  
9. Start the Conversation  

Prompt pattern:

> Build the Home page only using the content strategy document.

Not: “Build my website.”

## Positioning (always)

This website should feel like a **premium consulting firm**—not a marketing agency and not a coach.

- Generous white space  
- Restrained animations  
- Excellent typography  
- Editorial layouts  
- Calm visual hierarchy  
- Readability and clarity over flashy interactions  
- Every section supports Natalie as a **senior strategic advisor**
